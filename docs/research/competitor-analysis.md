```
Future Value = Initial Value × (1 + CAGR)^Duration
```

## 🎯 功能覆盖度评估

### CAGR 公式的 4 个变量：
```
CAGR = (Ending Value / Beginning Value)^(1/Years) - 1
```

**变量列表：**
1. Beginning Value (初始值)
2. Ending Value (结束值)
3. Years (年限)
4. CAGR Rate (增长率)
